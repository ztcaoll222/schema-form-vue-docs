布局与字段分组 ​

布局写在对象 schema 上，控制这一组字段怎么排列。支持 grid、card、tabs、steps 四种。

grid ​

ts
const schema = s.object({
  grid: s.object({
    a: s.string(),
    b: s.string(),
  }).layout('grid', { columns: 2, gap: 16 }),
});
  • columns：列数；
  • gap：字段间距；
  • 字段可以用 .span(n) 跨列。

card ​

ts
s.object({
  bio: s.string(),
}).layout('card', {
  title: '简介',
  collapsible: true,
});

tabs 和 steps ​

ts
const schema = s.object({
  tabs: s.object({
    basic: s.object({ name: s.string() }),
    advanced: s.object({ level: s.number() }),
  }).layout('tabs', { defaultActiveKey: 'basic' }),

  steps: s.object({
    first: s.object({ name: s.string() }),
    second: s.object({ level: s.number() }),
  }).layout('steps', { wizard: true }),
});

默认情况下，对象的每个直接子字段就是一个面板。需要把多个字段放进同一个面板时，可以用 items 显式分组：

ts
s.object({
  account: s.object({ username: s.string() }),
  security: s.object({ password: s.string() }),
}).layout('tabs', {
  items: [
    { key: 'account', label: '账号', fields: ['account'] },
    { key: 'security', label: '安全', fields: ['security'] },
  ],
});

fields 写的是对象的直接子字段名。没有列出的字段、重复字段或空分组会直接报错，避免字段被静默遗漏。

响应式 ​

  • Ant Design Vue 和原生 shadcn 风格适配器支持响应式列数/间距；
  • Element Plus 和 Naive UI 只支持固定值，文档中会明确说明；
  • 布局可以嵌套，字段级 .span() 只在最近的 grid 中生效。

插槽 ​

需要完全自定义布局时，可以使用字段插槽：

  • #field-{path}：替换整个字段；
  • #label-{path}：替换 label；
  • #error-{path}：替换错误提示。

具体用法见 API 速查。
