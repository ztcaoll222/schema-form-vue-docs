API 速查 ​

这一页列出日常最常用的 API。完整类型定义以包内 .d.ts 为准。

schema DSL ​

ts
import { s, type InferSchema } from '@schemavue/core';

const schema = s.object({
  name: s.string().label('名称').required('必填'),
  age: s.number().min(0).max(150),
  tags: s.array(s.string()).default([]),
  profile: s.object({ bio: s.string() }).layout('card', { title: '简介' }),
});

type Values = InferSchema<typeof schema>;

字段类型 ​

API说明
s.string()文本
s.number()数字
s.boolean()布尔
s.enum(values?)枚举；无参时为字符串
s.date()日期
s.richtext()富文本
s.object({...})对象
s.array(item)数组
s.union([a, b])多选一；值类型为成员类型并集
s.record(value)键不固定的对象，值为给定 schema
s.lazy(() => schema)递归/延迟 schema

常用链式方法 ​

API说明
.label(text)显示名称
.required(message?)必填
.min(n) / .max(n) / .length(n)范围/长度
.regex(rule, message)正则
.refine(fn, message)自定义校验
.default(value)默认值
.visibleWhen(rule)条件显示
.disabledWhen(rule)条件禁用
.validateOn(events)校验触发时机
.options(values)静态选项
.optionsHooks({...})异步选项
.layout(type, options)布局
.widget(name)指定字段组件语义
.transform(fn, output?)变换字段值（仅标量）
.pipe(schema)在变换后继续校验/转换

联合、动态键与变换 ​

ts
// 多选一：值类型为 string | number
const id = s.union([s.string(), s.number()]);

// 键不固定的对象：Record<string, string>
const labels = s.record(s.string());

// 标量变换：输入 string，输出 trim 后的 string
const name = s.string().transform((v) => v.trim()).pipe(s.string().min(1));

注意：

  • union 按成员顺序匹配，第一个匹配的成员胜出；
  • record 的键必须是字符串；__proto__ 等危险键会被拒绝；
  • transform 只支持标量、同步纯函数；表单值是变换后的值；
  • 当前 union / record 在表单里需要自定义 widget（.custom()），没有自定义 widget 会明确报错；表格默认跳过；
  • 函数变换不能完整表达为 JSON Schema，序列化时会在诊断里说明或报错。

创建组件 ​

ts
import { createSchemaVue, uiAdapter, richTextMd } from '@schemavue/vue';
import { elementPlusAdapter } from '@schemavue/element-plus';
import { MilkdownEditor } from '@schemavue/milkdown';

const { SchemaForm, SchemaTable } = createSchemaVue()
  .use(uiAdapter(elementPlusAdapter))
  .use(richTextMd(MilkdownEditor));

createSchemaVue() 返回的组件已经绑定了适配器和可选能力；不需要再给组件传 adapter。

表单 ​

vue
<SchemaForm :schema="schema" v-model="values" />

常用 props：

Prop说明
schemaschema 对象，或返回 schema 的 getter（动态 schema）
modelValue表单值（配合 v-model）
validateOn校验触发时机
messages覆盖错误文案
initialValues初始值

messages 用来覆盖表单级错误文案：

ts
const form = useForm(schema, {
  messages: {
    required: '这一项不能为空',
    min: '数值太小了',
  },
});

优先级：字段内联文案 > 表单 messages > 语言包 > 内置文案。目前只支持静态文案；如果文案需要在运行时整体切换，请重新创建表单实例。

headless 表单 ​

ts
import { useForm } from '@schemavue/form/headless';

const form = useForm(schema);
form.values;
form.errors;
form.touched;
await form.validate();
await form.handleSubmit();
form.reset();

异步选项 ​

ts
s.enum().optionsHooks({
  searchable: true,
  pageSize: 20,
  dependencies: ['province'],
  async load({ keyword, page, pageSize, signal }) {
    return fetchOptions({ keyword, page, pageSize, signal });
  },
});
  • searchable: true 会显示搜索入口；
  • pageSize 开启“加载更多”；
  • dependencies 指定依赖字段，依赖变化时重新加载；
  • load 返回选项数组或 { options, hasMore }；
  • 缓存、重试、防抖由业务在 load 中实现。

布局 ​

ts
s.object({...}).layout('grid', { columns: 2, gap: 16 });
s.object({...}).layout('card', { title: '基本信息', collapsible: true });
s.object({...}).layout('tabs', { defaultActiveKey: 'basic' });
s.object({...}).layout('steps', { wizard: true });

字段级跨列：.span(n)。

表格 ​

ts
const { SchemaTable } = createSchemaVue().use(uiAdapter(elementPlusAdapter));

<SchemaTable :schema="schema" :data="rows" />

常用能力：列显隐、排序、行选择、索引列、操作列、虚拟滚动；表格是只读展示，不内置编辑和导出。

富文本 ​

ts
const { SchemaForm } = createSchemaVue()
  .use(uiAdapter(elementPlusAdapter))
  .use(richTextHtml(RichTextEditor))
  .use(richTextMd(MilkdownEditor));
  • s.richtext() 默认 HTML；
  • s.richtext({ format: 'markdown' }) 使用 Markdown 编辑器；
  • 未注入编辑器时降级为 textarea；
  • 媒体上传、压缩、裁剪由业务通过 hooks 实现，库不内置上传管线。

JSON Schema ​

ts
import { toJsonSchema, fromJsonSchema } from '@schemavue/json-schema';

const { json, diagnostics } = toJsonSchema(schema);
const { def } = fromJsonSchema(json);
  • 支持可序列化 schema 子集；
  • 支持 $defs/$ref、异步 $ref、可选的 Ajv 校验（@schemavue/json-schema/validate/ajv）；
  • 函数字段等不可序列化内容会在 diagnostics 中说明。
