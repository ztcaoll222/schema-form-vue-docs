富文本 ​

富文本字段是可选能力，按需安装编辑器；不安装时字段会退化为普通 textarea。

支持的编辑器 ​

包格式说明
@schemavue/tiptapHTMLTiptap 编辑器，带工具栏、图片策略和 sanitize
@schemavue/milkdownMarkdownMilkdown WYSIWYG，GFM 支持
@schemavue/tiptap-markdownMarkdown基于 Tiptap 官方 Markdown 能力

接入 ​

ts
import { createSchemaVue, uiAdapter, richTextHtml, richTextMd } from '@schemavue/vue';
import { elementPlusAdapter } from '@schemavue/element-plus';
import { RichTextEditor } from '@schemavue/tiptap';
import { MilkdownEditor } from '@schemavue/milkdown';

const { SchemaForm } = createSchemaVue()
  .use(uiAdapter(elementPlusAdapter))
  .use(richTextHtml(RichTextEditor))
  .use(richTextMd(MilkdownEditor));

字段格式 ​

ts
const schema = s.object({
  html: s.richtext(),                          // 默认 HTML
  markdown: s.richtext({ format: 'markdown' }), // Markdown
});

format 决定字段值存 HTML 还是 Markdown；编辑器按格式选择。

安全 ​

  • HTML 内容在展示前必须 sanitize；Tiptap 包提供 @schemavue/tiptap/sanitize；
  • 图片地址默认只允许 http(s) 和根相对路径；
  • javascript:、data:、blob: 等危险协议默认拒绝；
  • Markdown 中的原始 HTML 不会执行；
  • 不要把未经处理的用户输入直接交给 v-html。

图片与媒体 ​

库不内置上传、压缩、裁剪或媒体库。需要时通过编辑器的 hooks 接入自己的上传服务：

  • 编辑器负责把文件变成任务、显示占位、展示进度和插入结果；
  • 业务负责请求、压缩、裁剪、重试、取消和 CDN 地址；
  • 不使用 hooks 时不会显示上传入口。

表格和代码块 ​

  • Tiptap 支持表格和代码块，可按需启用；
  • Markdown 的表格、任务列表、删除线等由编辑器能力决定；
  • 序列化是语义等价的，不保证 Markdown 字符串逐字一致。

体积 ​

编辑器都是独立入口，按需加载；没有使用富文本的页面不会下载编辑器代码。
