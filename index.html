schema-form-vue用 schema 描述表单，把 UI 留给适配器

TypeScript + Vue 3 · 一套 schema 生成表单、表格和校验 · 可切换 Element Plus / Naive UI / Ant Design Vue / 原生控件

开始使用
在线演示

🧩

schema 决定结构与类型

用 s.object / s.string / s.enum 描述字段；TypeScript 自动推导表单值类型，不需要手写两套定义。支持 union、record 和 transform 等进阶 schema。

🛡️

校验与联动是内建能力

必填、范围、正则、自定义校验、条件显示、跨字段联动；错误显示和可访问性属性自动处理。

🔌

换 UI 库不重写 schema

适配器负责把字段渲染成具体组件；同一份 schema 可以切换 Element Plus、Naive UI、Ant Design Vue 或原生控件。

📋

表单和表格来自同一份描述

同一 schema 可生成可编辑表单和只读表格；列定义、枚举选项、格式化逻辑复用。

⚡

异步与复杂交互可组合

异步选项、远程搜索、分页加载、取消请求、动态 schema、JSON Schema 互操作，按需引入。

🎨

富文本按需选择

HTML 用 Tiptap，Markdown 可用 Milkdown 或 Tiptap 官方 Markdown；不装编辑器就不增加主包体积。
