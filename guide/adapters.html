选择 UI 适配器 ​

schema-form-vue 的字段描述与 UI 库无关。你只需要选择一个适配器，把字段渲染成对应的组件。

适配器安装包适合
Element Plus@schemavue/element-plus项目已经在用 Element Plus
Naive UI@schemavue/naive-ui项目已经在用 Naive UI
Ant Design Vue@schemavue/ant-design-vue项目已经在用 Ant Design Vue
原生控件（shadcn 风格）@schemavue/shadcn-vue想减少 UI 运行时依赖，或需要完全自定义样式

怎么选 ​

  • 项目已有组件库：直接选对应适配器，样式和交互与现有页面一致；
  • 想减少依赖：选 @schemavue/shadcn-vue，使用原生 input/select，可通过 CSS 变量定制外观；
  • 需要富文本：适配器负责字段容器，富文本编辑器由 @schemavue/tiptap、@schemavue/milkdown 或 @schemavue/tiptap-markdown 提供，二者可以组合使用；
  • 需要表格：安装 @schemavue/table，它与适配器共享枚举、日期、布尔等格式化能力。

切换适配器 ​

ts
import { createSchemaVue, uiAdapter } from '@schemavue/vue';
import { elementPlusAdapter } from '@schemavue/element-plus';

const App = createSchemaVue().use(uiAdapter(elementPlusAdapter));

换成 Naive UI：

ts
import { naiveUiAdapter } from '@schemavue/naive-ui';

const App = createSchemaVue().use(uiAdapter(naiveUiAdapter));

同一份 schema 可以直接复用；值、校验和布局语义保持一致，只有组件外观和交互细节由 UI 库决定。

自定义适配器 ​

如果现有适配器不满足需求，可以实现一个自定义适配器：提供基本字段组件、表单容器和可选的布局能力，然后交给 uiAdapter()。具体字段接口见 API 速查。
