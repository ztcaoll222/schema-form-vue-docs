当前版本 ​

0.1.0（开发中，尚未发布到 npm）

已经具备：

  • schema DSL、类型推导、内置校验；支持 union、record、transform/管道；
  • Element Plus / Naive UI / Ant Design Vue / 原生控件四种适配器；
  • 表单布局（grid/card/tabs/steps）、数组字段、动态 schema；
  • 异步选项、远程搜索、分页加载、取消请求；
  • SchemaTable 只读表格、列定义、排序、选择、虚拟滚动；
  • 后端数据 ↔ 表单值映射；
  • JSON Schema 双向转换与可选 Ajv 校验；
  • Tiptap HTML、Milkdown Markdown、Tiptap Markdown 三种富文本编辑器；
  • 中/英/日/韩等多语言文案；
  • 可访问性属性、SSR 友好、按需加载。

接下来计划 ​

方向状态
发布到 npm（确定 license、scope、版本策略）规划中
更完整的表单/表格文档与示例进行中
提交钩子、表格服务端加载钩子规划中
更多 DSL 表达力（union/record 等）候选
可选的 Vite+ 工具链评估已评估，暂不迁移

版本策略 ​

  • 0.x 版本优先保证 API 可用和文档清晰；
  • 小版本会补充能力和修复问题，破坏性变更会写进发布说明；
  • 1.0 之前不承诺完全稳定的内部实现细节，但会尽量保持公开 API 兼容。
