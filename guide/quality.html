可靠性 ​

schema-form-vue 的每个版本都会跑完整测试、覆盖率、浏览器交互和可访问性检查。下面是可以直接验证的结果，而不是口头承诺。

质量是怎么保证的 ​

  • 类型优先：不使用显式 any，schema 推导出的表单值类型参与编译检查；
  • 行为测试：表单、表格、适配器、富文本、异步选项、动态 schema 都有对应的行为测试；
  • 适配器一致性：多个 UI 适配器运行同一组表单行为测试，减少“换库后行为变了”的风险；
  • 浏览器验证：用 Playwright 覆盖主题、懒加载、交互和可访问性；
  • 安全边界：富文本 URL 白名单、HTML sanitize、危险路径防护、循环引用防护。

bash
pnpm test

浏览器测试需要先启动 playground：

bash
pnpm -C playground dev
pnpm exec playwright test tests/e2e

安全说明 ​

  • 富文本显示 HTML 时，使用库提供的 sanitize 或你自己的 sanitizer；
  • 图片和链接 URL 默认只允许 http(s) 和根相对路径，危险协议会被拒绝；
  • 表单路径访问只使用自有属性，避免原型污染；
  • 循环引用和非法 schema 会安全失败，不破坏已有表单状态。

更详细的验证记录在仓库的 docs/test/ 与 docs/review/ 中，面向贡献者，不作为使用文档。
